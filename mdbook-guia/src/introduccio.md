# Introducció

Aquest llibre és una **guia pas a pas** per aprendre a crear un llibre amb **mdBook**.

mdBook és una eina que permet crear llibres digitals a partir de fitxers **Markdown**.  
És molt útil per:

- Documentació de projectes
- Apunts de classe
- Manuals tècnics
- Guies pas a pas, com aquesta 😉

## Què aprendràs en aquest llibre?

Al final d'aquesta guia sabràs:

- Instal·lar `mdBook`
- Crear un nou projecte de llibre
- Entendre l'estructura bàsica d'un projecte mdBook
- Construir i visualitzar el llibre en el teu navegador
- Publicar el llibre a internet amb **GitHub Pages**

## Requisits previs

Per seguir aquesta guia és recomanable:

- Tenir nocions bàsiques de **terminal / línia de comandes**
- Saber editar fitxers de text (amb VS Code, per exemple)
- Tenir instal·lats:
    - **Rust** (i `cargo`)
    - Opcionalment, **Git** si vols publicar el projecte a GitHub

Si alguna d'aquestes coses et sona una mica llunyana, no passa res: t'aniré guiant pas a pas.
